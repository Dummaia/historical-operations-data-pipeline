# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-18

### Added

- Multi-workbook and multi-sheet Excel ingestion.
- Snapshot-date extraction and source-level lineage.
- Column, identifier, text, numeric and date normalization.
- One-record-per-process-per-day consolidation.
- Follow-up date extraction and age calculation.
- Quality report with machine-readable JSON output.
- Parquet, Excel and optional PostgreSQL persistence.
- Deterministic synthetic snapshot generator.
- CLI, SQL analytics examples, tests and CI workflow.
