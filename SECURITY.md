# Security policy

## Supported version

Security updates are applied to the latest release.

## Reporting a vulnerability

Please report potential vulnerabilities privately to
[Eduardo Maia](mailto:maiae3381@gmail.com). Do not open a public issue with
credentials, personal data or exploit details.

## Data handling

This repository contains only synthetic data generation logic. Never commit
production spreadsheets, credentials, email addresses, internal URLs or
customer identifiers.
